# BUG-015

## Title
500 Internal Server Error returned by `GET /api/items/{id}` and `DELETE /api/items/{id}` due to missing item ID field.

---

# Summary

The Items API fails when retrieving or deleting a specific item by ID. Both the GET and DELETE handlers attempt to access an `id` field that does not exist in the article data, causing a `KeyError: 'id'` exception.

Instead of returning the requested item, deleting the item, or providing a valid error response, the API crashes and returns a 500 Internal Server Error.
