# Status Meaning

## Open
Bug has been reported

## Assigned
Developer is working on it

## Fixed
Developer says it is fixed


## Ready for Retest
Waiting for QA


## Verified
QA confirmed the fix


## Closed
Bug is complete


## Reopened
QA found the problem still exists


## Deferred
Fix postponed


## Duplicate
Same as another bug


## Cannot Reproduce
QA cannot reproduce the issue
