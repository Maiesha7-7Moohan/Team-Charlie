# BUG-003

---

# Title

Invalid HTTP status code `40` returned by `DELETE /api/items/1` when item is missing.

---

# Summary

The deletion handler in `app.py` returns an invalid HTTP status code `40` instead of a standard `404` when attempting to delete a non-existent item ID, causing HTTP protocol parsing errors in REST clients.

# Preconditions

- Flask development server running on `http://127.0.0.1:5000`.
- Target item ID (e.g., `1`) does not exist in `data/articles.json`.

---

# Steps to Reproduce

1. Open Thunder Client or preferred REST client.
2. Set HTTP method to `DELETE`.
3. Set request URL to `http://127.0.0.1:5000/api/items/1`.
4. Click **Send**.

---

# Expected Result

Server returns HTTP status code `404 Not Found` along with JSON payload `{"error": "Item not found"}`.

---

# Actual Result

Server returns an invalid status code `40` along with JSON payload `{"error": "Item not found"}`.

---

# Console Errors
